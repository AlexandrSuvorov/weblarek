# Интернет-магазин «Web-Larёk»

«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component

Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`

#### Класс Api

Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter

Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` - хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

### Данные

#### Интерфейс Product

Интерфейс `IProduct` описывает структуру данных для продукта. Он содержит шесть полей:

- `id` - Уникальный идентификатор продукта. Тип данных `string`.
- `description` - Описание характеристик и особенностей. Тип данных `string`.
- `image` - Ссылка на изображение продукта. Тип данных `string`.
- `title` - Краткое название или заголовок. Тип данных `string`.
- `category` - Категория, к которой относится товар. Тип данных `string`.
- `price` - Цена продукта. Тип данных `number` или `null`, если цена не указана.

#### Интерфейс Buyer

Интерфейс `IBuyer` описывает структуру данных покупателя. Он содержит четыре поля:

- `payment` - Тип платежа `TPayment`. Тип `TPayment` содержит в себе строку, описывающую способ оплаты (например: «наличными» или «банковской картой»).
- `email` - Почта покупателя. Тип данных `string`.
- `phone` - Номер телефона покупателя. Тип данных `string`.
- `address` - Адрес покупателя. Тип данных `string`.

#### Интерфейс ICatalogFromApi

Интерфейс `ICatalogFromApi` описывает структуру данных каталога товаров, полученных из API. Он содержит два поля:

- `total` - Общее количество товаров в каталоге. Тип данных `number`.
- `items` - Массив товаров. Тип данных `IProduct[]`.

#### Интерфейс IOrder

Интерфейс `IOrder` описывает структуру данных заказа. Наследуется от `IBuyer` и содержит два поля:

- `total` - Общая сумма заказа. Тип данных `number`.
- `items` - Массив идентификаторов товаров в заказе. Тип данных `string[]`.

#### Интерфейс IOrderResult

Интерфейс `IOrderResult` описывает структуру результата создания заказа. Он содержит два поля:

- `id` - Уникальный идентификатор созданного заказа. Тип данных `string`.
- `total` - Общая сумма заказа. Тип данных `number`.

#### Класс Catalog

Класс `Catalog `отвечает за хранение и управление списком товаров.

Поля класса:

- `items: IProduct[]` - массив всех товаров. Данными является массив интерфейсов `IProduct`.
- `selectedItem: IProduct | null` - товар, выбранный для подробного отображения. `null` начальное значение.

Методы класса:

- `set catalogItems(items: IProduct[])` - сохраняет массив товаров, полученного в параметрах метода. Ожидает на входе массив `IProduct[]`.
- `get catalogItems(): IProduct[]` - возвращает массив всех товаров. Возвращает массив `IProduct[]`.
- `get selectedProduct(id: string): IProduct | null` - возвращает товар по его уникальному идентификатору. Ожидает на входе идентификатор товара с типом данных `string`. Возвращает товар, если найдено совпадение или возвращает `null`, если совпадение не найдено.
- `set selectedProduct(item: IProduct)` - сохраняет товар для подробного отображения. Ожидает на входе интерфейс `IProduct`
- `getSelectedItem(id: string): IProduct | null` - возвращает выбранный товар. Ожидает на входе идентификатор товара с типом данных `string`. Возвращает товар, если найдено совпадение или возвращает `null`, если совпадение не найдено.

#### Класс Basket

Класс отвечает за хранение товаров, добавленных в корзину.

Поля класса:

- `items: IProduct[]` - массив товаров, добавленных в корзину. Данными является массив интерфейсов `IProduct`.

Методы класса:

- `get basketItems(): IProduct[]` - возвращает массив товаров, находящихся в корзине. Возвращает массив `IProduct[]`.
- `addItem(item: IProduct)` - добавляет товар в корзину, который был получен в параметре, в массив корзины. Ожидает на входе интерфейс `IProduct`, добавляемую в корзину.
- `removeItem(item: IProduct)` - удаляет товар из корзины, полученный в параметре из массива корзины. Ожидает на входе интерфейс `IProduct`, удаляемую в корзину.
- `clearBasket()` - очищает корзину.
- `get getTotalPrice(): number` - возвращает общую стоимость всех товаров в корзине. Возвращает значение с типом данных `number`.
- `get getItemsCount(): number` - возвращает количество товаров в корзине. Возвращает значение с типом данных `number`.
- `hasItem(id: string): boolean` - проверяет наличие товара в корзине по его id. Ожидает на входе идентификатор товара с типом данных `string`. Возвращает значение с типом данных `boolean`.

#### Класс Buyer

Класс отвечает за хранение и управление данными покупателя.

Поля класса:

- `payment: TPayment` - способ оплаты. Ожидает на входе тип `TPayment`
- `address: string` - адрес покупателя. Тип данных `string`.
- `phone: string` - телефон покупателя. Тип данных `string`.
- `email: string` - email покупателя. Тип данных `string`.

Методы класса:

- `set buyerItem(data: Partial<IBuyer>)` - сохраняет переданные данные покупателя. Позволяет обновлять отдельные поля, не затрагивая остальные.
- `get buyerItem(): IBuyer` - возвращает все данные покупателя. Возвращает интерфейс `IBuyer`
- `clearItem()` - очищает все данные покупателя.
- `validateItem(): Partial<Record<keyof IBuyer, string>>` - выполняет валидацию данных. Возвращает объект с ошибками, где ключ - это поле, а значение - текст ошибки. Если поле валидно, оно отсутствует в объекте.

#### Класс CatalogApi

Класс `CatalogApi` отвечает за взаимодействие с API для получения каталога товаров и отправки заказов.

Поля класса:

- `api: IApi` - экземпляр интерфейса API для выполнения HTTP-запросов.

Методы класса:

- `constructor(api: IApi)` - создаёт экземпляр класса с переданным интерфейсом API. Ожидает на входе интерфейс `IApi`.
- `getCatalogProducts(): Promise<ICatalogFromApi>` - получает список товаров из каталога. Выполняет GET-запрос к `/product`. Возвращает промис с данными каталога типа `ICatalogFromApi`.
- `postOrder(value: IOrder): Promise<IOrderResult>` - отправляет заказ на сервер. Выполняет POST-запрос к `/order` с данными заказа типа `IOrder`. Возвращает промис с результатом заказа типа `IOrderResult`.

### Классы представления (View)

#### Класс Card

Абстрактный класс `Card` является родительским классом для карточек товаров. Наследуется от класса `Component`.

Поля класса:

- `titleElement` - защищенный элемент для отображения названия товара.
- `priceElement` - защищенный элемент для отображения цены товара.

Методы класса:

- `set title(value: string)` - устанавливает название товара. Ожидает на входе тип `string`.
- `set price(value: number | null)` - устанавливает цену товара. Ожидает на входе тип `number` или `null`. Если значение равно `null`, отображает текст Бесценно.

#### Класс CardInBasket

Класс `CardInBasket` отвечает за отображение товара в корзине. Наследуется от класса `Card`.

Интерфейсы класса:

Интерфейс `ICard` наследуется от интерфейса `IProduct`.
- `index` - порядковый номер товара в корзине. Тип данных `number`.

Интерфейс `ICatalogActions`.
- `deleteButtonElement` - кнопка удаления товара из корзины.

Поля класса:

- `indexElement` - защищенный элемент для отображения порядкового номера.
- `deleteButton` - защищенный элемент для отображения кнопки удаления товара из корзины.

Методы класса:

- `set index(value: number)` - устанавливает порядковый номер товара в корзине. Ожидает на входе тип `number`.

#### Класс CardCatalog

Класс `CardCatalog` отвечает за отображение карточек товаров в каталоге.

Тип `TCardCatalog` в него входят поля `id`, `title`, `image` и `category` из интерфейса `IProduct`. Остальные поля игнорируются.

Интерфейс `ICatalogActions`.
- `showCard` - событие на карточке, которое отображает превью карточки.
 
Поля класса:

- categoryElement - элемент для отображения категории товара.
- imageElement - элемент для отображения изображения товара.

Методы класса:

- `set category(value: string)` - устанавливает категорию товара и CSS-класс для оформления. Ожидает на входе тип `string`.
- `set image(value: string)` - устанавливает изображение товара. Ожидает на входе тип string.

#### Класс CardPreview

Класс `CardPreview` отвечает за отображение подробной информации о товаре.

Тип `TCardPreview` в него входят поля  `image`, `category` и `description` из интерфейса `IProduct` и добавляет в тип `buttonText: string` и `isDisabled: boolean`. Остальные поля игнорируются.

Класс `ICatalogActions`.
- `onButtonClick` - событие на кнопке, которое добавляет товар в корзину.

Интерфейс `CardPreview` наследуется от интерфейса `TCardPreview`.

- `imageElement` - элемент изображения товара.
- `categoryElement` - элемент категории товара.
- `descriptionElement` - элемент описания товара.
- `buttonElement` - кнопка добавления или удаления товара из корзины.

Методы класса:

- `set image(value: string)` - устанавливает изображение товара. Ожидает на входе тип `string`.
- `set category(value: string)` - устанавливает категорию товара и CSS-класс для оформления. Ожидает на входе тип `string`.
- `set description(value: string)` - устанавливает описание товара. Ожидает на входе тип `string`.
- `set buttonText(value: string)` - устанавливает текст кнопки.`Купить` или `Недоступно`. Ожидает на входе тип `string`.
- `set isDisabled(value: boolean)` - устанавливает состояние кнопки. Ожидает на входе тип `boolean`.

#### Класс HeaderView

Класс `HeaderView` отвечает за отображение шапки приложения. Наследуется от класса `Component`.

Интерфейс `ICounterBasket`.
- `counter` - отвечает за счетчик возле иконки корзины.

Поля класса:

- `counterElement` - элемент для отображения количества товаров в корзине.
- `basketButton` - кнопка открытия корзины.

Методы класса:

- `set counter(value: number)` - устанавливает количество товаров в корзине. Ожидает на входе тип `number`.

#### Класс GalleryView

Класс `GalleryView` отвечает за отображение каталога товаров. Наследуется от класса `Component`.

Интерфейс `CatalogData`.
- `items` - хранит массив из `HTMLElement`, где находят товары.

Поля класса:

- `catalogElement` - контейнер для отображения карточек товаров.

Методы класса:
- `set catalog(items: HTMLElement[])` -  устанавливает список карточек товаров в каталоге. Ожидает на входе массив элементов типа `HTMLElement[]`.

#### Класс ModalView

Класс `ModalView` отвечает за отображение модального окна. Наследуется от класса `Component`.

Поля класса:
- `closeButton` - кнопка закрытия модального окна.
- `modalElement` - контейнер содержимого модального окна.

Методы класса:

- `set content(value: HTMLElement)` - устанавливает содержимое модального окна. Ожидает на входе элемент типа HTMLElement.
- `open(): void` - открывает модальное окно.
- `close(): void` - закрывает модальное окно.

#### Класс BasketView

Класс `BasketView` отвечает за отображение корзины товаров. Наследуется от класса `Component`.

Интерфейс `IBasket`. 
- `basket: HTMLElement[]` - хранит массив товаров в корзине пользователя. 
- `total: number` - хранит сумму всех товаров в корзине. 
- `isValid: boolean` - устанавливает кнопку состояние. Если корзина пуста, кнопка "Оформить" будет недоступна.

Поля класса:

- `basketListElement` - контейнер товаров в корзине.
- `basketButton` - кнопка "Оформить".
- `totalPriceElement` - элемент отображения общей стоимости.

Методы класса:
- `set basket(items: HTMLElement[])`  - устанавливает список товаров в корзине. Ожидает на входе массив элементов типа `HTMLElement[]`.
- `set total(value: number)` - устанавливает общую стоимость товаров в корзине. Ожидает на входе тип `number`.
- `set buttonDisabled(value: boolean)` - изменяет состояние кнопки оформления заказа. Ожидает на входе тип `boolean`.

#### Класс Form

Класс `Form` является родительским классом для всех форм приложения. Наследуется от класса `Component`.

Интерфейс `IForm`. 
- `errors: { [key in keyof T]?: string }` - хранит массив ошибок. Если поле пустое, образится ошибка.
- `isValid: boolean` - устанавливает кнопку состояние. 

Поля класса:

- `errorElement` - элемент отображения ошибок формы.
- `buttonForm` - кнопка отправки формы.

Методы класса:

- `set errors(value: { [key in keyof T]: string })` - устанавливает текст ошибки формы. Ожидает на входе тип `string`.
- `set buttonDisabled(value: boolean)` - изменяет состояние кнопки отправки формы. Ожидает на входе тип `boolean`.

#### Класс FormOrder

Класс FormOrder отвечает за отображение формы оформления заказа. Наследуется от класса `Form`.

Интерфейс `IFormOrder`.
- `payment: "cash" | "card" | ""` - хранит метод оплаты.  Ожидает на входе тип `string`, одно из значений `"cash" | "card" | ""`.
- `address: string` - хранит адрес.  Ожидает на входе тип `string`.

Интерфейс `IFormOrderActions`.
- `paymentClick: (payment: TPayment)` - событие для кнопки, устанавливает способ оплаты. Ожидает на входе тип `TPayment`.
- `addressChange: (address: string)` - событие для поля ввода Адрес. Ожидает на входе тип `string`.
- `submitClick: ()` - кнопка "Далее". Заполняет модальное окно следующим контентов.

Поля класса:

- `payment` - кнопка выбора оплаты.
- `addressInput` - поле ввода адреса доставки.

Методы класса:
- `set payment(value: "card" | "cash" | "")` - делает кнопку активной.
- `set address(value: string)` - устанавливает адрес доставки. Ожидает на входе тип `string`.

#### Класс FormContacts

Класс `FormContacts` отвечает за отображение формы контактных данных. Наследуется от класса `Form`.

Интерфейс `IFormOrder`.
- `email: string` - хранит Email.  Ожидает на входе тип `string`.
- `phone: string` - хранит телефон покупателя.  Ожидает на входе тип `string`.

Интерфейс `IFormActions`.
- `emailChange: (email: string)` - событие для поля ввода Email. Ожидает на входе тип `string`.
- `phoneChange: (phone: string)` - событие для поля ввода номера телефона. Ожидает на входе тип `string`.
- `submitClick: ()` - кнопка "Далее". Заполняет модальное окно следующим контентов.

Поля класса:
- `emailInput` - поле ввода email.
- `phoneInput` - поле ввода телефона.

Методы класса:

- `set email(value: string)` - устанавливает email покупателя. Ожидает на входе тип `string`.
- `set phone(value: string)` - устанавливает телефон покупателя. Ожидает на входе тип `string`.

#### Класс SuccessView

Класс `SuccessView` отвечает за отображение успешного оформления заказа. Наследуется от класса `Component`.

Интерфейс `ISuccessView`.
- `total` - элемент отображения общей стоимости.

Интерфейс `ISuccessActions`.
- `onOrdered: ()` - Закрытие окна успешного оформления заказа.
- `closeButton: ()` - Закрытие модального окна.

Поля класса:

- `closeButton` - кнопка закрытия модального окна.
- `descriptionElement` - элемент отображения описания.

Методы класса:

- `set total(value: number)` - устанавливает сумму списания в сообщение об успешном оформлении заказа. Ожидает на входе тип `number`.

### Презентер (обработка событий)

В приложении обрабатываются следующие события:

`HeaderView`

- `basket:open` - вызывается при нажатии на кнопку корзины в шапке приложения. Презентер формирует содержимое корзины, передаёт данные в `BasketView` и открывает модальное окно с корзиной.

`GalleryView`

- `catalog:changed` - вызывается при изменении модели каталога. Презентер получает обновлённый список товаров, создаёт карточки `CardCatalog` и передаёт их в `GalleryView` для отображения.

- `card:select` - срабатывает при клике по карточке товара в каталоге. Презентер получает идентификатор выбранного товара и инициирует загрузку данных для отображения превью.

`ModalView`

- `modal:open` - вызывается при открытии модального окна. Презентер переводит компонент `ModalView` в активное состояние.

- `modal:close` - вызывается при закрытии модального окна. Презентер закрывает `ModalView` и очищает временное состояние интерфейса при необходимости.

`CardPreview`

- `card:add-product` - вызывается при добавлении товара в корзину. Презентер добавляет товар в модель `BasketView`, обновляет состояние карточки товара и счётчик товаров в `HeaderView`.

- `card:remove-product` - вызывается при удалении товара из корзины. Презентер удаляет товар из модели `BasketView`, обновляет состояние карточки товара и счётчик товаров в `HeaderView`.

`BasketView`

- `basket:change` - вызывается моделью `Basket` при изменении содержимого корзины. Презентер пересоздаёт список карточек `CardInBasket`, пересчитывает общую стоимость товаров и обновляет компонент `BasketView`.

- `basket:order` - инициирует первый этап оформления заказа. Презентер отображает форму `FormOrder` в модальном окне.

`CardInBasket`

- `basket:remove-product` - вызывается при удалении товара из корзины. Презентер удаляет товар из модели `BasketView`, обновляет состояние карточки товара и счётчик товаров в `HeaderView`.

`FormOrder`

- `form-order:payment` - Презентер устанавливает тип оплаты как в модели заказа и обновляет состояние формы.

- `form-order:address` - вызывается при изменении поля адреса доставки в форме `FormOrder`. Презентер валидирует адрес и при необходимости блокирует/активирует кнопку дальнейшего шага.

- `form-order:submit` - генерируется формой `FormOrder` после отправки данных первого шага оформления. Презентер сохраняет данные заказа и переключает интерфейс на форму контактных данных `FormContacts`.

`FormContacts`

- `form-contacts:submit` - вызывается при отправке формы `FormContacts`. Презентер формирует итоговый объект заказа на основе данных моделей `Buyer` и `Basket`, отправляет его на сервер и при успешном ответе инициирует событие `basket:success`.

- `form-contacts:email` - вызывается при изменении поля «Email» во `FormContacts`. Презентер валидирует Email и при необходимости блокирует/активирует кнопку дальнейшего шага.

- `form-contacts:phone` - вызывается при изменении поля «Телефон» во `FormContacts`. Презентер валидирует номер и при необходимости блокирует/активирует кнопку дальнейшего шага.

`SuccessView`

- `basket:success` - вызывается после успешного оформления заказа. Презентер очищает корзину и данные покупателя, создаёт компонент SuccessView и отображает сообщение об успешном оформлении заказа с итоговой суммой списания.

`Buyer` 

`buyer:change` - вызывается при валидации данных покупателя.
